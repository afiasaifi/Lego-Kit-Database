Python and Pandas Installation steps:
For Windows:
```
python -m pip install --upgrade pip
python -m pip install pandas
python scripts/check.py
```

For MacOS:
```
python3 -m venv .venv
source .venv/bin/activate

python -m pip install --upgrade pip
python -m pip install pandas
python scripts/check.py
```
